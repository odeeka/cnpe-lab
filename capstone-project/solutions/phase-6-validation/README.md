# Phase 6: Validation Solutions

This directory contains validation scripts and tests for the BookStore capstone project.

## Directory Structure

```
phase-6-validation/
├── README.md                    # This file
├── validate-all.sh              # Master validation script
├── phase-1-validation.sh        # Foundation validation
├── phase-2-validation.sh        # Application validation
├── phase-3-validation.sh        # Observability validation
├── phase-4-validation.sh        # Security validation
└── phase-5-validation.sh        # Reliability validation
```

## Usage

```bash
# Run all validations
./validate-all.sh

# Run specific phase validation
./phase-1-validation.sh
./phase-2-validation.sh
# etc.
```

## Scoring

Each phase is worth 20 points (100 total):
- Phase 1: Foundation (20 points)
- Phase 2: Application (20 points)
- Phase 3: Observability (20 points)
- Phase 4: Security (20 points)
- Phase 5: Reliability (20 points)

Passing score: 70 points
