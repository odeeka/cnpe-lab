## Certifications to Consider

Now that you've mastered the fundamentals, consider these certifications:

### **CKAD - Certified Kubernetes Application Developer**

- **Focus**: Application deployment and management
- **Difficulty**: Intermediate
- **Exam**: 2 hours, performance-based
- **Prerequisites**: Module 1 knowledge sufficient

### **CKA - Certified Kubernetes Administrator**

- **Focus**: Cluster administration and operations
- **Difficulty**: Intermediate-Advanced
- **Exam**: 2 hours, performance-based
- **Prerequisites**: Module 1 + some operational experience

### **CKS - Certified Kubernetes Security Specialist**

- **Focus**: Security hardening and compliance
- **Difficulty**: Advanced
- **Prerequisites**: CKA certification required

### **CNPE - Cloud Native Platform Engineer** (Your Goal!)

- **Focus**: Platform engineering, IDP, DevEx
- **Difficulty**: Advanced
- **Prerequisites**: All modules in this repo
